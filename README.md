# Colora

A calm, modern PDF annotation workspace designed for distraction-free editing.

Colora is a pastel-inspired PDF annotation and document editing application built for students, researchers, designers, and professionals. It combines powerful annotation tools with a clean, minimal interface that feels effortless to use.

---

## Features

### Document Management

- Open local PDF documents
- Import images (PNG, JPG, JPEG, WebP)
- Create a blank document
- Multi-page editing
- Export annotated documents as PDF

---

## Annotation Tools

- Freehand drawing
- Highlighter
- Text
- Sticky notes
- Signature
- Eraser
- Arrow
- Line
- Rectangle
- Ellipse
- Diamond
- Image insertion

## Design

Colora is designed to provide a calm editing experience without unnecessary visual clutter.

The interface uses:

- Soft lavender accents
- Warm cream backgrounds
- Muted charcoal typography
- Rounded components
- Gentle shadows
- Minimal layouts

The goal is to make document annotation feel simple, focused, and enjoyable.

---

## Workflow

1. Open a PDF or image, or create a blank document.
2. Select a tool from the left sidebar.
3. Adjust tool settings from the top toolbar.
4. Annotate directly on the page.
5. Navigate between pages and zoom as needed.
6. Export the finished document as a PDF.

---

## Design Goals

Colora is built around three ideas:

- Fast and intuitive annotation
- A clean interface that stays out of the way
- A polished visual style suitable for everyday work, screenshots, and presentations
