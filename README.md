# ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Esc` | Clear or exit the active tool |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Shift + Z` | Redo |
| `Ctrl/Cmd + Y` | Redo |
| `Ctrl/Cmd + O` | Open file |
| `Ctrl/Cmd + N` | Add a blank page |
| `Ctrl/Cmd + S` | Export as PDF |
| `H` | Highlighter |
| `V` | Hand / Select / Pan tool |
| `P` or `D` | Draw tool |
| `T` | Text tool |
| `S` | Signature tool |
| `E` | Eraser |
| `R` | Rectangle |
| `O` | Ellipse |
| `M` | Diamond |
| `L` | Line |
| `A` | Arrow |
| `N` | Note |
| `I` | Insert picture |
| `Delete` | Delete current page |
| `←` / `Page Up` | Previous page |
| `→` / `Page Down` | Next page |
| `+` | Zoom in |
| `-` | Zoom out |
| `0` | Fit page to width |
